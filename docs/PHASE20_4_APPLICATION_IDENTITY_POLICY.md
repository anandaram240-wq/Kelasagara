## 2. KEY ATTRIBUTES AND AUTHORIZATION POLICY

During device registration, the generated Android Keystore key must fulfill the following mandatory hardware-enforced authorizations:

1. **Algorithm**: ECDSA (`Tag 2 = 3` for EC; RSA keys are rejected for device signatures).
2. **Key Size**: 256 bits (`Tag 3 = 256` on curve `secp256r1` / NIST P-256).
3. **Digest Authorization**: SHA-256 (`Tag 5 = 4`). Keys requiring MD5 or SHA-1 are rejected.
4. **Key Purpose**: Sign (`Tag 1 = 2` for `PURPOSE_SIGN`). Decrypt/Encrypt purposes are rejected.
5. **Key Origin**: Generated internally in hardware (`Tag 702 = 0` for `ORIGIN_GENERATED`). Imported keys (`ORIGIN_IMPORTED = 1`) or derived keys are strictly rejected.
6. **Public Key Match Invariant**: The Subject Public Key Info (SPKI) decoded from the attestation certificate must be byte-for-byte identical to the `publicKeyPem` submitted by the Android client.

## 3. CHALLENGE BINDING CONTRACT

Registration challenges generated by `DeviceRegistrationService` strictly bind the following parameters into a cryptographic token:

```typescript
export interface DeviceRegistrationChallenge {
  readonly challengeId: string;
  readonly nonce: string; // 32 bytes cryptographically secure random (hex)
  readonly uid: string; // Firebase Authenticated User ID
  readonly expectedPackage: string; // 'com.kelasagaara.kelasagaara'
  readonly purpose: 'DEVICE_KEY_ATTESTATION';
  readonly createdAt: number; // Unix epoch ms
  readonly expiresAt: number; // createdAt + 300,000 ms (5 minutes)
  readonly consumed: boolean;
}
```

### Invariants Enforced
- **Atomic Single-Use**: Challenges are marked `consumed: true` upon first verification attempt. Subsequent attempts trigger immediate `REGISTRATION_CHALLENGE_REPLAY_ERROR`.
- **UID Cross-Account Theft Protection**: If Worker A attempts to submit a registration challenge issued for Worker B, registration aborts with `UID_CHALLENGE_MISMATCH`.
- **Replay & Expiration Protection**: Challenges older than 300 seconds are rejected with `CHALLENGE_EXPIRED_ERROR`.
